## 修复内容

- 仅剩 v1 滚动备份时，先成功解析，再逐字节保留 `workspace.json.v1.bak` 并恢复 schemaVersion 2 主文件。已有归档不覆盖；损坏文件不创建主文件或演示数据。
- 研究卡关联自选、原文或财务记录后，代码与名称只读，并在保存校验中再次检查。其他研究字段仍可编辑并保留历史；研究其他公司需新建卡，避免旧公司的证据被用于新公司。
- 公司查询同时校验返回的代码、名称及市场。实测 `stock/get` 提供市场字段 `f107`，沪市为 1，深市及当前北交所接口为 0。

- 版本更新为 `0.2.1+3`；打包脚本从 pubspec 读取版本，为体验目录、ZIP、APK 和校验清单生成一致的名称。

```powershell
./tools/flutter.ps1 -Task check
cd app
../.tools/flutter/bin/flutter.bat test integration_test/native_services_test.dart -d windows
../.tools/flutter/bin/flutter.bat test integration_test/native_services_test.dart -d emulator-5574 --no-enable-impeller
../.tools/flutter/bin/flutter.bat test integration_test/v02_acceptance_test.dart -d windows
../.tools/flutter/bin/flutter.bat test integration_test/v02_acceptance_test.dart -d emulator-5574 --no-enable-impeller
../.tools/flutter/bin/dart.bat run tool/live_market_probe.dart
../.tools/flutter/bin/flutter.bat test tool/preview_test.dart --no-pub
```

原生测试使用独立测试模拟器；`emulator-5574` 是本轮实例，不代表其他环境的设备 ID。完整流程使用临时目录，不读取日常研究工作区或真实模型密钥。

跨端验收可在 Windows 运行时传入 `--dart-define=V02_EXPORT_FIXTURE=本机绝对路径`，将生成的虚构研究备份传到安卓，再传入 `--dart-define=V02_IMPORT_FIXTURE=安卓可读绝对路径`。测试通过界面粘贴导入并确认，重启后核对整份 JSON、稳定 ID、来源与财务关联、研究历史及上述风险结果。
