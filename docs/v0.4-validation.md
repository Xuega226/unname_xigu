# 未名溪谷 v0.4 验证记录

日期：2026-10-03。基于 v0.3 提交 2116637。功能、验证、两端发行构建与体验包已完成。

## 已完成行为

- 真实研究卡的「资料与财务 → 自动查找年报」固定该卡证券代码和交易所，查询最近三个已结束年度。巨潮公司查询返回值须同时匹配代码、A 股类别及沪/深 orgId 归属；北交所明确提示先手动导入。
- 获取年度报告全文，排除摘要、英文、审计和通知类公告，处理分页、缺失年份、不支持的修订标题和证券错配；原披露、修订版并列，没有默认勾选或自动覆盖。
- 多选后顺序下载，每份复用原生 PDF 解析、选页、单位与来源人工确认。下载文件只在核验确认后落盘；单份失败继续后续项目，可单独重试，取消停止余下队列，已保存项目保留。
- 每次请求最多 45 秒、目录 JSON 最多 2 MB、单份 PDF 最多 25 MB；仅访问两个明确的官方 HTTPS 主机，下载重定向再次验证主机。拒绝 HTTP、伪装域名、网址凭据、非标准端口、HTML、非 PDF 和不完整传输。连接与响应在超时/错误后回收。
- 同研究卡的公告身份及 SHA-256 防重复。公告原始标题、证券身份、公告 ID、原始报告期间、披露日期、修订标志、出处 URL 和获取时间保存为独立 origin；人工核验的字段与原始元数据同时保留。JSON 工作区仍为 schemaVersion 3，可选 origin 保持旧备份兼容。
- 下载后不自动调用模型；复用既有财务候选引用核验、人工选择与确认。修订来源默认数字披露版本为「未注明」，展示口径提醒，年度比较保留原有去歧义规则。
- 保存期间禁用重复提交与系统返回，批量窗口返回已成功保存的完整列表；查询/下载取消后的迟到结果不会写入工作区。
