# v0.7：可配置因子规则与评分

日期：2026-10-05。基线 `e72a4c8` / v0.6.1+10。主人已确认先完成可配置工具，示例默认不启用；继续采用单账户，不接入自动交易。交付版本0.7.1+11、schema7。

状态：P0已完成，231项离线测试、双端原生与双向备份、旧发行包覆盖升级通过；结果见 [v0.7.1验收](v0.7-acceptance.md)。

## P0

1. 增加量化研究页，覆盖最多10家自选。规则包含观察日期、报表口径、动量窗口、价格最大允许间隔、行业排除、指标、比较方向、阈值、权重及筛选开关。规则每次保存产生新版本，最多20版，明确复查条件与参数。
2. 初始没有启用策略。加载示例仍未启用；用户核对并明确确认后才计算。固定评分公式为 `100 × 命中规则权重之和 / 全部评分规则权重之和`，权重0规则可仅作筛选。缺失或不适用的参与规则阻止综合分及入选，不重分配权重。排名仅描述此自选样本。
3. 候选因子：扣非利润率、营收/扣非利润同比、经营现金与扣非利润之比、现金与有息负债之比、未复权收盘价、交易观测间隔动量、市销率。金融行业不套用泛财务比率。分项贡献图与上述公式一致，公司间同因子对照显示单位、原值和缺失原因。
4. 财务只使用口径匹配的整日历年原披露数据，归一金额单位；最新同期间冲突不猜测，缺值不回退旧报告掩盖。观察日前披露的数据才可用：由于现有资料只有日期，同日披露在次日才纳入。注明原文、报告期、披露日期和核验来源；修订/未知口径不可回写历史。
5. 估值需要单独核验的公司总股本、有效日期、披露日期和本公司来源。用 `价格 × 总股本 / 营业收入元` 计算市销率；不能将用户持仓数量代替公司股份。
6. 历史行情只维护来源明确的未复权收盘价。支持原有公开行情来源的手动获取及标准JSON预览导入，最多10份、每份500项。校验证券、日期、价格和完整结构，失败保留旧记录，17点前不纳入当天未结束日线。动量注明观测间隔，不把缺日序列宣称为完整交易日历。
7. 引入带日期资金流水。首次启用时用户确认覆盖起点，既有累计入/出金作为期初总额保留，不拆造以前的流水；后续实际入/出金记录更新累计本金。取消与保存失败保持旧数据，不从资产、买卖或持仓变化推导资金流。已有流水时累计字段由其维护。
8. JSON备份携带参数版本、股份证据、行情与流水，兼容schema1–4、6，保留精确旧版归档，拒绝多账户schema5。持仓导入与历史恢复保留新量化和资金字段。
9. 结果关联既有公司研究和复查入口；计算、阈值修改、行情获取不自动修改持仓、研究结论或调用AI。连续估值与现金流历史仍不够时净值、高点回撤保持未知。回测属v0.8。

## 验收

- 虚构、可手算样例验证所有公式、阈值/权重变化、同分稳定排序、金融行业、非正分母、缺失值和披露/行情时点。
- 规则未确认无评分；参数保存、重开、跨端备份后结果一致；取消/保存失败不覆盖。
- 标准历史行情坏行、来源错配、未来日期和重复日期拒绝；旧数据保持。
- 资金流水覆盖起点、期初累计、日期及删除确认正确，后续持仓恢复保持流水与本金。
- 桌面、手机、大字体的规则编辑、全量结果、贡献与对照图通过，原有185项回归保持。
- Windows/Android原生、跨端备份、从v0.6.1发行包覆盖升级及重开，发行包、SHA-256、文档和可审阅提交齐全。

不把当前取回的历史资料声称为当时采集的快照；不补交易日、不推算复权、不计算伪造净值。公开行情接口的真实可用性单独记入验收，离线夹具不代替联网验证。
