# v0.7.3 验收记录

日期：2026-10-05（Asia/Shanghai）。基线 `2f89f79` / v0.7.2+12 / schema7，交付 v0.7.3+13 / schema8。以下验证已完成，范围见 [版本规划](v0.7.3-plan.md)和 [需求](ai-verification-requirements.md)。

## 实现范围

- 自动查找年报直接可见；下载与本地文字 PDF 均支持本机候选页和主动 AI 建议，预填期间与逐表单位，保留上下文、出处和人工路径。
- 单报告提取与独立上下文复核，程序检查指标名称、原始数字、来源、年度、单位、日期和报表口径；同页无关引用不能通过。
- 正常唯一候选默认纳入，异常/不足/不适用单列；一次报告级确认保存，语义例外记录依据，硬错误不允许绕过。
- 审计记录模型、版本、输入指纹、原文快照、逐项结果、选择和实际 usage（缺失为未知）。旧逐项确认保留含义，schema7 迁移前保存 `.v7.bak`。
- 取消/关闭即失效任务，迟到结果不追加复核或写入；保存失败可显式重试，重复提交不创建重复财务，工作区变化阻止旧快照覆盖。

## 验证

静态分析无问题，**285 项离线测试通过**。新增覆盖正常默认集合、负数/缺失、错年度/错指标、同页无关复核引用、候选重排去重、不同用量不重复采纳、准备版本、取消/关闭迟到、保存失败重试与 390px 两倍字体；既有金额、证据、持仓、规则与资金流水断言保留。15 张财务预览位于 [preview-v0.7.3](preview-v0.7.3/)，桌面、手机及大字体的摘要、依据、异常与最终动作均可阅读，无布局溢出。

Windows 及 Android API29 专用模拟器原生入口各 **12 项通过**，均使用生产控件与真实临时磁盘；报告准备使用生产 PDF 引擎解析虚构原件，模型为明确虚构响应。一份报告依次完成本机选页、一次 AI 准备、一次原文采用、准备证据备份恢复、同 PDF 新准备版本及财务期间/口径预填。Android 验收 34 秒，Windows 最终验收 23 秒（均不含构建时间）。

Windows 首次原生准备测试发现正文使用 ISO 日期范围，而本机仅识别中文日期及年度标题；针对实际原文先验证失败，再增加严格成对 ISO 范围解析后通过。多个本期/比较期范围仍保留未知，不为通过测试猜年份。

Windows 导出 schema8 备份在 Android 实际写盘重开，Android 导出在 Windows 同样恢复；金额、逐项证据、确认方式、审计、规则、历史行情和资金流水完整保持。离线/原生测试未读取真实密钥或账户，也未发送付费模型请求。

Windows、Android 均使用真实 v0.7.2+12 发行包启动两份虚构工作区（含财报原文的 rich、含量化规则的 quant），覆盖升级到 v0.7.3+13 后再关闭重开。四组结果均为 schema7→8；除 schemaVersion 外，原始夹具、旧版写盘、升级后与重开后的 JSON 严格相等，财务、金额、证据、规则、历史行情与资金流水未变，旧财务没有被标记为 AI 预核验。Windows 两份 `.v7.bak` 与旧版写盘原始字节完全一致；Android 原 PDF 哈希保持，运行期间未见致命崩溃。

Windows Release 构建通过（37.7 秒），Android Release 构建通过（47.9 秒）。Android 安装后实际 versionName 为 0.7.3、versionCode 为 13，已安装 APK 与交付 APK 的 SHA256 一致。发布插件注册文件未包含 integration_test。实际 Android 发行包画面见 [截图](preview-v0.7.3/android-v073-release.png)。

## 边界

模型测试使用虚构响应及标注夹具，不读取真实密钥、不调用付费服务；当前没有真实模型准确率结果。来源和数字可追溯不保证模型语义一定正确，正常字段仍由用户明确采纳；扫描件 OCR、跨报告批次、自动采纳、回测、券商直连及自动交易仍为后续范围。Android 沿用测试签名，其他 Windows 电脑完整部署未验证。
