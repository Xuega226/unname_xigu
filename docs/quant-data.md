# v0.7 量化数据基础

历史日线和按日期的资金流水独立保存在本地单账户工作区，随完整 JSON 备份一起迁移。导入历史不会更新持仓数量、持仓价格、账户现金或公司研究。流水更新累计转入、累计转出与净本金，不自动更新账户现金。因子阈值和权重由用户确认，示例默认不启用。

## 历史日线

在“量化研究”的“量化数据基础”中选择“导入历史 JSON”，粘贴单个序列对象，先校验并预览，再确认保存。已有相同 `symbol` 时显示旧、新范围并要求确认替换；取消、解析失败或保存失败都保留旧历史。每次只导入一个公司，最多保存 10 个序列。单个序列也可通过“导出 JSON”复制，另行保存为 `.json` 文件。

```json
{
  "id": "fictional-history-SH-600001",
  "symbol": "SH:600001",
  "adjustment": "unadjusted",
  "source": "https://example.org/fictional-history",
  "fetchedAt": "2026-10-01T10:00:00Z",
  "bars": [
    {"date": "2026-09-28", "close": 10},
    {"date": "2026-09-29", "close": 11},
    {"date": "2026-09-30", "close": 12}
  ]
}
```

这是虚构数据，用于测试格式与手算，不代表证券实际行情。完整样例位于 `examples/quant-price-history.json`。`symbol` 必须包含匹配代码的交易所（`SH`、`SZ`、`BJ`）；来源须为 HTTPS 地址，获取时间须明确时区。每个序列包含 1 至 500 根日线，日期严格升序、不重复、合法，且不晚于获取时间对应的中国日期；收盘价必须为有限正数。无效行不能被静默跳过，日期混序也不能自动整理后掩盖输入问题。

“获取公开历史日线”使用东方财富公开未复权日线接口，请求约两年、最多 500 根。响应需核对代码和市场，验证每行的日期与收盘价。中国时间 17 点前排除已通过校验的当日条目，避免把未结束行情当作日收盘价。失败保留旧历史并提示检查网络、代码或改用 JSON。此功能不连接券商账户。

当前只接受 `unadjusted`（未复权），不自动推算前复权或后复权。除权除息可能导致价格跳变，因此基于该序列的动量和波动率必须保留未复权口径。首尾日期只说明已取得的数据范围，**不证明期间交易日完整覆盖**；停牌、来源缺失或新上市都可能造成间断。数据不足时应显示缺失原因，不能填零、拼接其他公司或其他复权口径。

## 按日期的资金流水

旧备份只有累计转入和转出，没有逐笔日期。首次启用时确认覆盖起点，原累计值原样作为期初汇总保留，**不拆造旧流水**。覆盖起点以前不具备逐笔资金记录；启用时净本金不变。

覆盖起点以后可新增、编辑和删除实际发生的转入或转出，保留日期、方向、金额和来源说明。日期不得早于覆盖起点或在未来，金额为正数、最多两位小数，每笔不超过一万亿元，最多 1000 条；ID 不可重复。删除需要确认，取消或保存失败不会改变流水或本金。新增已经计入期初汇总的金额会造成重复计算，录入前须核对。

累计转入 = 期初累计转入 + 已录入转入流水；累计转出 = 期初累计转出 + 已录入转出流水；净本金 = 累计转入 − 累计转出。来源说明默认“手动录入”，可修改为可核对的凭证描述。它说明资料来源，不是账户绑定或交易执行指令。

资金流水不是资产净值序列。历史日线、当前持仓、期初资金汇总均不能重建过去的真实持仓和资产；**v0.7 不据此伪造账户净值、最大回撤或回测收益**。后续净值分析需要连续资产快照、完整资金流及明确计算口径。
