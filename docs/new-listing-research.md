# 新上市公司怎样补全研究资料

以下以力勤资源（001246，深圳 SZ）为例，官方公告核对日期为 2026-10-03。

## 先确定资料来源

“自动查找年报”目前仅查询沪深 A 股近三个完整年度的年报正文。查询无结果不能证明公司没有披露财务资料，也不能证明未披露年报。

力勤资源于 2026-09-30 在深圳主板上市。本次 A 股年报查询未找到 2023、2024、2025 年年报，但上市公告书确认招股说明书包含这三个年度的经审计财务资料，以及 2026 年上半年的经审阅财务信息。可以先用这些发行上市资料建立研究记录。

| 官方文件 | 用途 |
| --- | --- |
| [正式招股说明书，2026-09-24](https://static.cninfo.com.cn/finalpage/2026-09-24/1225579578.PDF) | 查历史财务报表、非经常性损益、主营业务、竞争格局、募投项目和风险因素。优先使用正式稿。 |
| [上市公告书，2026-09-29](https://static.cninfo.com.cn/finalpage/2026-09-29/1225586094.PDF) | 确认证券代码及上市日期，核对审计截止日、上市前最新经营信息与披露性质。第五节为财务会计资料。 |

已核对正式招股说明书共 431 页。历史财务表从 **PDF 第 168 页（文内页码 167）** 起，包含 2025、2024、2023 年列；这里的合并报表单位为元。2026 年上半年信息在 PDF 第 38–39 页附近，部分概览表单位为万元，须逐表核对。

## 在当前版本中操作

1. 进入力勤资源研究卡的“资料与财务”，点击“导入财报 PDF”，选择官方文件。标题保留“招股说明书”或“上市公告书”，填写实际披露日和原始网址，选择业务、财务及风险相关原文页，按选页实际内容填写期间和单位。
2. 招股说明书同时包含多期财务数据。需要 2023、2024、2025 年记录时，按年度分别使用“添加原文片段”：摘录带完整期间表头和指标名的连续原文，保留同一招股书网址、实际披露日期、准确页码，并填写该年度和原文单位。不能把多期文件标成一份普通年报，不能重复导入相同 PDF 来模拟三份年报。
3. 点击“核对财务字段”，按对应年度列分别保存营收、扣非净利润、经营现金流、期末现金和有息负债。开始/结束日期填该年 01-01 / 12-31，披露日期仍为文件实际披露日。缺失字段留空，合并/母公司和原披露/重述口径按原文核对。
4. 也可选取上述按年度添加的原文片段，使用“AI 提取财务候选值”，填写所需年度和口径，逐项对照原文后保存。当前 PDF 候选校验要求候选期间与导入文件期间一致；多期 PDF 的历史年度应先分年添加原文片段。新增片段保留网址及页码，但没有自动关联的“定位 PDF 原页”按钮，可回到已归档 PDF 查阅。
5. 业务、产能、客户、成本及风险的片段可用于“AI 研究草稿”。保留引用，核对后再接受为研究卡版本。

2026 年上半年另建 01-01 至 06-30 的记录，并注明经审阅。全年预测、业绩预计和未经审计经营数据作为单独研究资料保留；当前财务记录没有独立预测或审计状态字段，勿将预测数字作为已实现财务值保存，也勿将半年度金额与全年直接比较。

如果某页多项指标单位不同，请分开添加原文片段；“期末现金”与“货币资金”等概念不一定相同，有息负债也不能直接用负债合计替代。缺少明确指标定义时暂时留空。

## 后续自动化方向

可在年报查询之外增加独立的“新上市公司资料”入口，获取正式招股说明书、上市公告书和审计/审阅报告；对一份文件里的多个报告期分别标注，并区分已实现、预测、审计与审阅状态。目前这些文件需要手动导入，自动回退和多期 PDF 直接提取尚未实现。
