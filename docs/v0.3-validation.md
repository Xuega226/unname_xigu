以下为历史实测。本工作区在 2026-10-04 将第三轮实现复用于 v0.2.1 修复基线，本次构建、迁移和跨端结果单独记录在 [v0.3.1 验收记录](v0.3-acceptance.md)。历史真实模型、公开年报与系统选择器结果不计作本次重测。

## 功能与数据验证

- `flutter analyze --no-pub` 无问题；默认离线测试 41 项通过，其中新增 18 项涵盖候选值、财报页关系、v2 迁移、历史、复查和完整应用流程。普通测试使用虚构资料与模拟模型，不调用账户 API。
- Windows 与 Android API 29 x86_64 模拟器通过原生 PDF 和共享界面流程：提取两页中文测试 PDF、渲染 PNG、拒绝扫描/加密/损坏文件、按 SHA-256 读写原件、备份恢复页码及原文。取消、重复文件与无文字页不能保存。
- 两端系统文件选择器实际选择虚构 PDF 后，返回字节并通过原生提取。Windows 测试使用系统打开对话框；Android 使用 DocumentsUI 的下载目录。测试用三份 PDF 共约 10 KB，均为本项目自制的虚构数据。
- 完整应用测试覆盖「资料与财务 → PDF 选页 → 手动填期间及单位 → 勾选确认 → 保存原件与片段 → 提取候选 → 逐项选择和人工确认 → 保存带证据财务 → 恢复备份 → 追加复查」。两端原生集成测试和离线 widget 测试分别运行；模拟模型响应与真实调用分开记录。
- v1/v2 格式兼容导入，v2 实际磁盘迁移保留原始 `.v2.bak` 字节。页码越界、来源/财报元数据错配、跨公司引用、重复文件、候选与已存数字不一致或缺少证据时拒绝恢复。
- 财务候选检查原始数字完整 token，不把 1 当成 100、金额百分比当成金额；拒绝不存在的来源、改写摘录、期间/口径/单位错配。缺失保持 null，利润与经营现金流支持负数。
- 多年度测试验证元/万元/亿元换算；母公司与合并、季报与年报、未知口径、重述、重复年度、断档、缺值、零/负基数不自动同比；负数结果不产生误导性增长率。
- 复查日期、待验证清单、判断依据和同公司来源随备份保留。再次编辑保留上次快照；成立/不成立必须有判断依据。版本对照在小屏纵向显示，桌面并排显示。
- 390×844 与 1280×1000 页面及新对话框无溢出，中文预览已逐张检查，见 `docs/preview-v0.3/`。

## 真实 PDF 与模型调用

- 使用[福耀玻璃官网 2025 年报](https://www.fuyaogroup.com/upfiles/investor/202603/1773747544359.pdf)作为公开样本，Windows 原生引擎提取 189 页，渲染并检查第 8 页。本轮测试下载不属于产品自动抓取功能；原报告未提交到 Git。
- 使用 Windows 本机已保存的 DeepSeek 配置发送第 8 页原文和来源元数据，模型 `deepseek-flash` 返回约 1839 ms。没有发送账户持仓、私人研究或修改用户工作区。
- 与原表人工核对的 2025 年本期数：营收 45,787,435,563 元；归母扣非净利润 9,164,684,348 元；经营现金流 12,055,090,552 元。三项候选逐字引用与原始数字检查通过，确认构造的记录在备份恢复后仍有效。该页缺少现金与有息负债，保存为空。
- 无密钥结果保存在本机 `artifacts/deepseek-financial-v0.3.json`，原生渲染在 `artifacts/fuyao-page8-native.png`。显式 opt-in 测试为 `integration_test/live_financial_test.dart`，需自行提供官方 PDF 的本地路径；不是默认测试的一部分。
- Codex MSIX 的空安全存储影子文件在调用期间临时移开，让插件读取普通用户 AppData 的配置，结束后恢复。没有显示、导出或提交密钥。安卓没有配置用户密钥，本轮实际模型调用仅在 Windows 验证。

## 构建环境与边界

- Windows x64 Release 与 Android 通用 Release APK 构建完成。Windows 产品版本为 0.3.0+3；目录随包包含 `pdfium.dll`、`dartjni.dll` 及所需运行库。复制到另一目录后，发行进程启动检查及随包 PDFium 解析两页中文 PDF 通过；未据此宣称已在其他电脑完成部署。
- 最终 Android Release 包实际覆盖安装 v0.2 Release，versionCode=3 / versionName=0.3.0。只读测试模拟器中的虚构升级工作区保留现金 1234、旧研究假设和 `Round3_upgrade_preserve_v02` 复查标记，迁移为 schemaVersion 3；`.v2.bak` 与原文件 SHA-256 相同，发行界面截图已检查。测试通过 ADB 写入的虚构文件先修正为应用的原有所有者和 SELinux 标签，未触及真实手机或用户研究。
- 使用本机 Flutter 3.47.4-0.0.pre-1 / Dart 3.13.4；新增 PDF 引擎通过 `pdfium_flutter` native assets 打包 PDFium，文件选择通过官方 `file_selector`。Pub 锁文件保留具体依赖版本。
- 安卓初次构建因 C 盘 Pub 插件与 F 盘项目触发 Kotlin 增量缓存的不同磁盘根路径错误；设置 `kotlin.incremental=false` 后成功。模拟器测试使用软件 GPU 与 `--no-enable-impeller`；界面测试在输入后收起真实软键盘，按设备实际尺寸运行。
- JSON 备份不包含原 PDF，仅携带选页文字、文件名、校验值、页码及研究资料。在另一设备仍能看已存文字，查看原页需要另行复制原件并重新关联 SHA-256。最多 25 MB / 1000 页，保存最多 25 页 / 24 万字符，单次模型最多 6 万字符，备份最多 800 万字符。
- 摘录与数值检查只证明内容存在于选定原文，不能自动证明指标含义、本期列、公告真实性和公司归属。界面保留人工确认门槛；模型结果不自动写入研究。
- 未测安卓实机、其他 Windows 电脑、全部厂商系统与大字体场景。Android APK 使用测试签名。扫描 OCR、按代码自动下载、云同步、系统后台通知和交易均未实现；财报自动下载仍计划第四轮。
