# v0.7.2 验收记录

2026-10-05（Asia/Shanghai）。基线 `bea6924` / v0.7.1+11，交付 v0.7.2+12、schema7。按用户要求先简化前端页面，并使用项目已有的未名子股票分析图标。

## 调整

- 总览保留主要账户指标与研究进度，增加公司研究和账户风险的快捷入口。
- 研究卡默认展示摘要，完整内容单独阅读；AI 草稿、趋势、复查与版本集中在更多菜单。
- 资料窗口分为资料原文与财务核验，添加动作集中为一个菜单；原页、全文及核验依据按需展开。
- 量化页保留结果、缺失原因和启用状态，参数说明、股本、贡献与比较详情按需展开；高级设置保持校验并在错误时自动展开。
- 历史行情和资金流水明细折叠，原有获取、导入和维护入口保留。
- 复用 1254 × 1254 原始图标，生成应用内 512px、Windows 七尺寸 ICO 和 Android 五密度启动图标，仅缩放完整画面。

操作见 [页面操作说明](ui-simplification.md)。预览使用虚构数据，位于 [preview-v0.7.2](preview-v0.7.2/)。

## 验证与发行

静态分析无问题，**238 项离线测试通过**，包括原有 231 项以及新增资料导航、负值/缺失展示、高级设置校验和取消保留的覆盖。旧完整流程仅补充新菜单及展开步骤，原有金额、证据、取消和备份断言保留。未调用模型或读取真实账户。

两份离线预览工具通过，生成 35 张桌面、390px 手机及两倍字体图片。全应用预览确认网络请求为零、导航前后备份逐字一致，手机固定动作可达，无布局溢出。量化预览还覆盖负现金情形；图片中的公司与数字均为虚构。

Windows 生产 PDF 原生流程通过：自动查询的虚构响应、失败重试、取消、选页、人工财务核验、负现金流、趋势、复查、去重、原文恢复和 PDF 重新关联。量化原生流程独立运行通过（37 秒）：示例需确认、评分 75、取消不写入、资金本金 10500 元、现金不变、证据入口和备份重开恢复。首次同命令运行两个原生入口时，第二个入口未能建立调试连接；改为单入口运行后通过。

Android API29 专用模拟器的相同生产 PDF 原生流程通过（115 秒），量化原生流程通过（47 秒）。两端均使用真实临时磁盘、生产界面与生产 PDF 引擎，公告和模型响应为虚构替身，系统文件选择使用固定样本，未联调券商或付费模型。
