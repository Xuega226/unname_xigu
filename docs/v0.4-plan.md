# 未名溪谷 v0.4：按代码获取财报

状态：功能与两端验证完成，详见 [v0.4 验证记录](v0.4-validation.md)。基于 v0.3 提交 2116637，在 `codex/weiming-xigu-v0.4` 开发，保留已有第二/第三轮 PR，第四轮独立提交。

## 目标

在真实公司研究卡输入的证券代码基础上，查询官方披露平台近三年年报，人工选择公告并批量下载，逐份复用 PDF 选页、公司/报告期/单位核验后保存。接入已有 DeepSeek 财务候选与年度比较流程。

## 范围

- A 股年报正文，先验证沪深来源；不支持的市场明确提示，可继续手动导入。当前年份未披露的年报不视为可取得，缺失年份明确展示。
- 保存公告标识、证券身份、查询来源、下载 URL、标题、报告期间、披露日期、修订标记、获取时间与文件校验值。修订版与原披露并列，不默认覆盖旧证据。
- 多选公告后顺序下载；逐份核验选页后保存，单份错误可以重试。公告与内容重复不再次导入，取消不改变尚未确认的研究数据，已成功保存的项目保留。
- 文件大小/响应大小限制、超时、来源主机校验、无效 PDF、来源证券错配、分页与不完整结果处理。
- Windows 与安卓模拟器验证；旧工作区升级与 JSON 往返兼容，不读取测试所不需的用户资料或密钥。

## 验收

1. 一家真实公司的代码可以查到近三年的官方年报，至少一份通过真实下载与原生 PDF 解析。
2. 取消、错误响应、超大文件、HTML 冒充 PDF、跨公司公告、重复公告均不能修改已保存财务数据。
3. 原披露/修订版、缺失年份、部分下载失败明确显示；重试不重复保存已成功项目。
4. 下载 → 核验并保存选页 → 模拟 AI 候选核验 → 备份恢复 → 多年度比较，两端走通。真实下载与模拟模型结果分别记录。
5. 静态检查、相关自动化测试、两端发行构建与安装包生成完成，提交和推送 Git，创建可审阅的草稿 PR。

OCR、季度批量获取、云同步、后台提醒与全市场扫描留待后续。第三轮原有人工导入与 PDF 原件单独传输规则保留。
