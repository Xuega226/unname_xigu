# v0.7 可配置量化规则

量化研究只比较当前最多10家自选公司。初始没有启用规则，“载入未启用示例”保存后仍不计算综合分。核对观察日、资料与参数后勾选确认，才启用当前版本；任意参数修改都会清除本次确认。每次保存创建新版本，保留最近20版，早期版本请先导出完整备份。复用历史版本也需重新确认。计算与保存参数不修改研究判断、持仓或现金，也不调用模型。

## 评分与筛选

综合分固定为 `100 × 命中规则的权重之和 ÷ 全部评分规则的权重之和`。每项正权重规则命中时贡献其权重占总权重的百分比，不命中贡献0；这是阈值命中评分，并非将因子原值标准化。勾选“用于筛选”的规则必须全部通过才能入选；未通过筛选的公司仍可显示已知分数，但不进入入选排名。

权重0规则必须用于筛选，可以只筛选、不评分。全部权重为0时，通过且资料齐全的公司标为“筛选通过（仅筛选）”，无综合分、不参加排名。任何参与规则缺失或不适用时，整体分数保持未知、不入选，不将缺失当成零、不重分配权重。行业排除阻止入选；同分按证券标识稳定排列，排名仅表示当前入选自选样本。

例如虚构公司扣非利润率20%，营收同比25%；规则为利润率≥15%、权重3、用于筛选，营收同比≥30%、权重1、不用于筛选。第一项贡献75分，第二项贡献0分，总分75，筛选通过。若营收缺失，总分未知；若利润率改为10%且阈值不变，则不入选。图表直接显示同一公式的贡献，未知贡献无填充条。

## 指标定义

| 因子 | 计算 | 单位及约束 |
| --- | --- | --- |
| 扣非净利率 | 扣非净利润 ÷ 营业收入 ×100 | %；营收须为正，利润可为负 |
| 营收同比 | （本年营收−上年营收）÷上年营收 ×100 | %；相邻整日历年、上年基数为正 |
| 扣非利润同比 | （本年扣非利润−上年扣非利润）÷上年扣非利润 ×100 | %；上年为正，本年负值仍可计算 |
| 经营现金流/扣非净利 | 经营活动现金流净额 ÷ 扣非净利润 | 倍；扣非利润须为正，现金流可为负 |
| 现金/有息负债 | 已核验现金字段 ÷ 已核验有息负债字段 | 倍；负债须为正，零负债不推为无穷大 |
| 未复权收盘价 | 观察日前最近有效未复权收盘价 | 元；检查最大允许自然日间隔 |
| 未复权动量 | （末根收盘价÷N个观测间隔前收盘价−1）×100 | %；N间隔需N+1根日线，N为2–250 |
| 市销率 | 收盘价 × 经核验公司总股本 ÷ 营业收入元 | 倍；营收为正，独立股本证据可用 |

银行、保险、证券行业不使用此处泛财务比率；可使用资料充足的价格、动量规则。利润同比缺乏正基数时仍为未知，不能用绝对值替换分母。不同单位的财务金额换算为元后计算；公司间对照只比较同一定义、同一单位，并显示各自报告期，不表示报告期完全一致。

## 观察日与证据

观察日采用该日开始前的信息集，严格**不含观察日**的财务披露和日线。当前只记录披露日期，没有时分，因此同日披露次日才纳入。行情获取在中国时间17点前排除当日条目；17点后取得的当天日线可保存，但只在次日观察时参与因子计算。今天取回过去的资料不能证明当时已采集到这些资料。

财务只采用所选合并/母公司口径、原披露、1月1日至12月31日整年度记录，并校验原文来源、公司和披露日。最新年度缺少字段时不回退旧年度掩盖，最新相同期间出现多个记录时标为冲突，不猜测采用哪份。同比还需前一日历年匹配记录；修订、未知口径、非整年度或时间不符合的资料不会被用来补算。

市销率要求另录公司总股本：证券标识、股数、生效日、披露日、本公司原文来源和人工核验状态。未核验、未来生效/披露、来源不匹配或相同最新日期冲突时保持未知；不会使用用户持仓股数。结果明细保留公式、原值、原始单位、期间、披露日期、来源ID、标题、页码及URL，可返回对应研究卡继续人工核验和复查。

未复权动量可能包含除权除息跳变。日线长度仅表示已取得的观测数量，缺日不能当成完整交易日历，不补零、不插值、不拼接复权口径。历史日线与资金格式见 [数据基础](quant-data.md)。v0.8 回测仍需固定策略、完整时间可用性、成本和成交限制；v0.7 不生成回测、净值或高点回撤。
