# 页面操作说明（更新至 v0.7.3）

五个主页面继续对应研究总览、公司研究、账户风控、复查日志和量化研究。总览提供「开始研究公司」和「查看账户风险」两个快捷入口。

## 公司研究

研究卡先展示主营业务、当前判断和反面证据的摘要。点击「阅读完整研究」阅读全部五节内容及更新日期，点击右上角编辑图标修改原文。

「资料与财务」保留为直接入口。「更多研究操作」集中提供生成 AI 草稿、多年度财务变化、复查计划与清单、研究版本对照。AI 草稿仍需主动发送原文、核对引用并确认接受；演示工作区不能调用模型。

## 资料与财务

「资料原文」直接显示「自动查找年报」；窗口底部「添加资料」可导入财报 PDF 或添加原文片段。下载和本地导入都会建议关键页、期间与单位，可预览调整，主动「AI 选页与预填」最多一次请求。点击「采用范围并保存原文」只表示采用资料范围，不声称已逐项核验财务。

- 「资料原文」展示 PDF 和原文片段列表，点击资料标题展开全文与出处。点击 PDF 文件名展开原页查看、重新关联原件与重新准备选页入口；新准备版本保留旧证据，原件缺失时仅覆盖已有片段。
- 「财务核验」直接提供「AI 预核验」，人工「核对财务字段」为次级入口。选定单份报告后主动发送原文，通常提取与复核两次请求；正常唯一字段默认纳入，查看摘要后一次确认保存。异常可排除、补资料或记录人工处理依据，硬错误不能越过。

负数、缺失和不适用直接显示；选择范围或修改参数会使旧核验失效，可停止等待。报告级确认、旧逐项人工确认与人工录入分别显示。成功添加资料后返回资料原文，成功保存财务后停留在财务核验；来源与复核依据可展开。

## 量化研究

默认展示当前规则的启用状态、观察日、规则数量和筛选评分结果。「查看当前参数」展开完整配置，「计算说明」展开公式与数据要求。「因子明细与分项贡献」展开具体贡献图，「公司间因子对照」展开比较图。

规则编辑器先显示名称、观察日、财务口径和因子规则。「高级设置」包含动量窗口、价格时效、行业排除及复查约定；这些值始终参与保存和计算，折叠只影响显示。高级字段错误时自动展开并阻止保存。总股本资料、历史行情明细和资金流水明细按需展开，添加、获取与导入入口保留。

示例默认不启用，修改后的配置必须重新核对确认；缺失资料不会按零分补齐。
