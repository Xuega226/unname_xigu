# 未名溪谷 v0.3：财报导入与研究复查

状态：功能完成，验收详见 [v0.3 验证记录](v0.3-validation.md)。基于第二轮提交 c2b6697，保留第二轮 PR，第三轮独立提交。

## 目标

选一家真实公司，手动选择文字型财报 PDF 或粘贴公告，选择原文页并保存出处；发送选定片段到 DeepSeek 提取候选财务值，逐项核验后保存；查看同口径多年度变化、研究版本差异和复查清单；通过备份在安卓恢复并追加复查。

## 本轮范围

- PDF 原件保存在本机应用目录，选页原文、原始文件名、SHA-256、页码、报告期、披露日期和出处保存在工作区。备份携带选页原文及校验信息；原 PDF 单独传输或重新关联，不嵌入文本备份。导入后可查看本机原页和提取文字，扫描件、加密或损坏文件给出明确状态。
- 财务候选值展示指标名称、原始数值、单位、报告起止日期、合并/母公司口径和来源摘录。数值必须能在原文中定位，来源有效并经人工确认后才进入财务记录，缺失保留为空。
- 多年度表按报告期间类型和报表口径分组，年度与季度不混算。明确单位换算，口径不明、重复或重述记录不自动计算增长率；负数与零基数不产生误导性同比。
- 保存研究卡历史快照，展示字段差异；设置下次复查日期，维护待验证清单与核验状态。使用本地到期展示，不创建系统后台提醒。
- schemaVersion 3，v1/v2 兼容导入；迁移前保留原版本备份；Windows 与安卓模拟器验证 PDF、备份恢复及研究复查。真实模型调用与模拟响应结果分别记录。

## 验收

- 取消导入或生成、错误 PDF、无文字页、来源错配、数字与原文不符、未勾选人工核验均不得改变已保存研究或财务记录。
- 同一 PDF 不重复导入同一研究卡；文件名不能用于拼接落盘路径；不同公司的文件/来源不得互相引用。
- 新旧备份往返保留持仓、研究、原文、核验数字、研究历史、复查日期和清单；密钥不进入备份。
- 桌面与 390×844 手机界面无溢出，两端构建通过，模拟器升级不丢已有记录。

## 第四轮及以后

按股票代码自动查找和下载财报、批量多年度获取、季报去重、OCR、云同步、全市场选股和回测留待后续。安卓实机本轮未连接，按用户选择先用模拟器。
