## 已验证

- Flutter 静态检查无问题，96 项普通功能测试全部通过。其中新增 16 项持仓导入/自动读取/界面测试；其余为已有行情、研究、年报、财务核验、持久化与响应式布局回归。
- CSV 测试覆盖中文表头、前导零、引号逗号、UTF-8 BOM、UTF-16 BOM、总持仓与可用股数区分、市价与成本价区分、缺列/多义列/损坏行拒绝。
- JSON 测试覆盖完整快照、账户类型/币种限制、重复代码、交易所冲突、非整数/负数量、缺市价、旧日期/旧时间、未来时间、无时区与无效日历日期拒绝。
- 导入前核验勾选、取消和损坏文件不写入；确认后整账户替换现金/数量/价格，保留研究与资金流。人工修改持仓会标记修改，并关闭自动读取。
- 自动读取测试使用临时文件，验证前台暂停、SHA-256 去重、错误保留旧记录、保存失败重试、配置恢复、账户错配持久关闭、停止后的在途读取不写入，以及停止/绑定并发不会恢复旧绑定。
- v1/v2 原有迁移用例更新到 v4；新增 v3 原始字节备份和迁移测试。旧文件保存为对应 `.v1.bak` / `.v2.bak` / `.v3.bak`，研究与持仓备份往返通过。
- Windows 原生集成测试 `integration_test/broker_import_native_test.dart` 通过：在隔离目录创建虚构快照，导入真实本地文件、绑定与更新、损坏文件保留、停止自动读取、重开读取磁盘数据。测试注入文件选择结果，**没有验证本轮系统选择器交互**；没有读取真实用户工作区或券商凭据。

## 构建与体验包

- Windows x64 Release 构建成功，exe 为 `weiming_xigu.exe`。
- Android Release APK 构建成功，使用原有测试签名和 applicationId，版本号升为 7。构建工具的 SDK XML / Java 8 警告没有导致失败。
- 体验包由 `tools/package.ps1` 打包；Windows 保留 exe、DLL、data、使用说明和虚构持仓样例。APK 与 ZIP 的 SHA-256 记录在 artifacts 目录。
- 本轮没有连接 Android 模拟器或实机（adb devices 列表为空），未进行安卓安装升级或系统文件选择器的重新验证。手机尺寸测试不能替代实机验证。

## 边界与待完成

用户尚未确定券商，本轮交付的是**持仓文件导入及文件更新后的自动读取**。没有真实券商登录、账户鉴权、官方 API 或 QMT 适配器，没有真实账户联调。文件不会自行生成，外部适配器需要按 JSON 约定持续输出完整账户快照。

目前仅支持一个 CNY 普通股票账户、沪深北六位 A 股整数持仓与现金；没有成本价/券商浮盈同步、融资负债、多币种/多账户汇总或自动交易。CSV 需手动导出和填写现金/日期，GBK 文件需另存 UTF-8；JSON 自动读取限 Windows 前台运行。

选定券商后需验证官方接入条件、只读授权、账户归属、现金口径、持仓完整性、同日成交变化、断线恢复与 Android 部署方式，再完成账户直连。
